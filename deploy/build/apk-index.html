Cartopolis for Android

A 3D map of the real world you can walk around in and fly out of, built from OpenStreetMap. This is the phone build: the map viewer, free, no account, no ads, nothing collected. It comes from us rather than from the Play Store, so Android will question it twice on the way in — both dialogs are below, with what to tap.

Upgrading from Viberfox? This release renames the app, and Android identifies an app by a hidden id rather than by its name — so this installs beside the old one instead of replacing it, and the old one will never update again. Uninstall Viberfox by hand once you have this running. Nothing is carried over automatically; the map viewer keeps no account and no world data, so there is nothing to migrate.

Installing it

  1. Tap Download the APK above. If the browser warns that this type of file can harm your device, choose Download anyway.
  2. Open the downloaded file — from the notification, or from Files → Downloads.
  3. Android says For your security, your phone is not allowed to install unknown apps from this source. Tap Settings, turn on Allow from this source, then press Back. Some phones word this as Install unknown apps.
  4. Tap Install.
  5. This is the step people stop at. Play Protect shows Unsafe app blocked or Play Protect doesn't recognize this app's developer, and offers only More details and Don't install. Tap More details — that reveals Install anyway. Tap it.
  6. If it offers to Send app for scanning, either answer is fine; the install continues.

That warning means Google has never seen this app before, not that anything was found in it. Every app not distributed through the Play Store gets it. If you would rather check for yourself, the sha256 above is of the exact file this page links to.

Signed with the project's own key, so later builds install straight over this one — but only one build is kept here at a time, and a fresh one replaces it whenever the code changes. Nothing on this page needs an account.

It is early software: the phone build is the map viewer, typing goes through the app's own on-screen keyboard rather than your usual one, and it wants a reasonably recent phone. There is also a browser version at cartopolis.org.
