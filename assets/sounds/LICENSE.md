# City sounds — where each one comes from

Every file here is cut from a recording released under **CC0 1.0** (public
domain dedication), checked on the recording's own page on 2026-10-20. No
attribution is required; it is given anyway. The Freesound files are cut from
the site's high-quality previews, not the originals.

`steps/<surface>-<n>.ogg` are single footsteps, peak-normalised, mono.
`ambience/<bed>.ogg` are 30-second seamless loops, loudness-normalised to one
level (−20 LUFS) so the mix in `systems::ambience` decides how loud each is.
How they were cut is in `docs/notes/city-soundscape.md`.
