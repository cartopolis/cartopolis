# docs/img

Images used by the docs and the top-level README.

`screenshot-1.png` … `screenshot-3.png` are generated in-app: open the developer
panel (**Ctrl + Shift + D**) and use the **📷 Capture slot N** button, which saves
a clean, chrome-free capture to this directory and cycles through the three slots.
See [Taking screenshots](../manual.md#taking-screenshots).
