# Community tab, profile and settings: mockup

A design proposal, not code. Everything marked **new** does not exist in the
app today.

The app's chat list was cluttered and misnamed: "Chats" twice at the top, the
new-chat choices opening inside the list, every community topic its own row,
voice and blocked people at the foot of the list, and a person button that
opened Contacts but looked like "me". There was no profile page, and Settings
was reachable only from World's ☰ menu. Access tokens could only be managed on
the web page.

v1 renames the switch to **Community | World** (the web page's words), keeps
only conversations on the list, moves "new" into a sheet, turns the person
button into your own disc opening a **You** page, and makes Settings a list of
pages that adds **Privacy and safety** and **Access tokens**.
