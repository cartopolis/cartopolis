Interest is a radius around each person, never a cell

Today every client receives every avatar every tick and every prim at the handshake. Instead each connection receives what is within reach of its person, found in a spatial index the server keeps. Peers' avatars and things sit in the same index with their server and freshness on them. Nothing about the world is cut up: no squares, no cells, no borders. NEW the per-connection frame; the index is an implementation detail.
