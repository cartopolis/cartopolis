Sign in from the communities people already have

v3. The sign-in options are Codeberg, Mastodon, Discord and Reddit, Google and GitHub, and an operator turns each on in Admin › People › Sign-in, not in a config file. A person who arrives through Discord or Reddit is offered the Cartopolis community linked to their server or subreddit, so the group moves across together. v1 and v2 hold what isn't repeated here: picking a name, linking by password, the app's hand-off to the browser and the account page. Everything is NEW.

Discord and Reddit

  • Discord asks for identify email, and adds guilds only if the server links communities (section 4). Discord says whether the address is verified, so it behaves like Google in v1: no mail link, and the password-once linking of v1 section 3.
  • Reddit asks for identity, and mysubreddits only when communities are linked. Reddit never gives an e-mail address, so it behaves like Mastodon in v2: the address is optional and u/annadv shows on the profile as confirmed.
  • Neither is free software, unlike Codeberg and Mastodon. They're there because that's where the groups we want to reach already are.

Dropped since v2

  • The garage44 button. A community's own login server can still be added in Admin (“Another OpenID server”), but cartopolis.org doesn't ship one.

Another OpenID server (a community's own Keycloak, Nextcloud, Forgejo…)
Switching a provider off stops new sign-ins with it. Accounts that also have a password or another provider keep working. Those that don't are listed so you can warn them first.

Choices made here

  • In the backend, not in cartopolis.toml, as asked. It's stored in world.db, takes effect without a restart, and needs the operator's manage sign-in permission (a new one in Roles).
  • Secrets are write-only. Once saved, a client secret shows as “set · replace”, never as text, and no API returns it. It's kept encrypted in the database with a key from the environment, so a copy of world.db alone doesn't give it away.
  • “Working” means tested. The Test button does a real round trip with the operator's own account. That catches a wrong redirect address before members see an error page.
  • The switch never strands anyone. Turning a provider off is allowed, but the alert counts the accounts with no other way in.

Notes

  • The same form for every provider, with its own three steps and link. Mastodon has no form, because the server registers itself with each Mastodon server on first use (v2).
  • “Only members of a linked server” lets a server open itself to exactly the groups it has linked, without opening registration to everyone. It's the one setting that goes further than the server-wide registrations open switch.
  • Self-hosted servers do the same with their own Discord application. Nothing is shared through cartopolis.org.

You can only link a Discord server you manage, or a subreddit you moderate. Discord and Reddit tell us which those are.

How it works

  • Proof of ownership: linking needs Manage Server on Discord, or moderator status on Reddit (mysubreddits), checked at link time. Nobody can claim a group they don't run.
  • Membership is checked once, at sign-in, and only matched against linked groups. We don't store anything else about which servers someone is in.
  • Joining is offered, not automatic. Both boxes start ticked, but the person can untick them, and leaving the Discord server later doesn't remove them here.
  • Already have an account? Linking Discord on the account page (v1 section 5) shows the same “your groups are here too” list.
