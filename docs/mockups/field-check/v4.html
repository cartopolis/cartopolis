CThe picture

  • Real left, Cartopolis right, same spot, same direction.
  • Under it: where, how accurate, which direction, which camera, when, and the app version: enough to render the same view again.
  • The data is a shot preset, the same format as docs/shots.toml, so the agent can put the camera back on exactly this view at any time with one command, before and after a fix:
[[shot]]
name   = "field-2026-10-15-1203"
group  = "field-check"
at     = [53.21830, 6.56790, 1.6]   # metres above the ground there
look   = [14.0, -9.0]               # pitch, yaw
roll   = 0.4                        # new
fov    = 68.0                       # new: the phone lens, vertical
date   = "2026-10-15"               # new: with time, the sun's position
time   = 12.05                      # UTC

[shot.measured]                     # new: data only, not rendered
accuracy_m = 0.01
ground_nap = 7.02                   # compare with AHN
camera     = "rear"
client     = "410d46f4"
cargo shots --shots docs/field-checks.toml --only field-2026-10-15-1203
  • Every check is kept in docs/field-checks.toml, so the walk becomes a set of views that can all be re-rendered after any change.
