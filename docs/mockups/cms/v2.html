Content pages v2 — JSX blocks, every text a $t, made through MCP

Proposed 2026-11-14; nothing here exists yet NEW. An agent writes a page through MCP as JSX made of the site's own components; the simulator parses it (never runs it), keeps its texts per language, and the browser draws it at /{lang}/{slug}.

1A page, as an agent sends it to put_page

Only components from the registry, only $t('…') for anything a reader sees. The second panel is the same call with one sentence typed in directly: refused as a whole, with the line and the reason.

2The page's texts, per language

Stored beside the page, not in a file in the repository. Each translation remembers which source sentence it translated: when the Dutch changes, the English turns stale instead of quietly describing the old sentence. A missing text falls back to the source language.
