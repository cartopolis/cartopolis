Communities v3: one menu for a person, sections by role

Decided after v2: only the owner appoints moderators; moderators delete messages and remove people from a topic or the whole community, because moderation is the community's; and the server's own admins act on a person from the same menu, in a section only they see. "Topic" stays. Everything here is new except the server actions, which exist today in the web admin pages.

* if "Members may start topics" is on. Server admins have no say inside a community they are not running: they can't read it (it is encrypted) and they don't delete its messages. Their reach is the account and, for a community that breaks the server's rules, deleting the community. A deleted message is hidden by every member's app; the server also stops delivering it to anybody who syncs later, which is what makes it more than a request.
