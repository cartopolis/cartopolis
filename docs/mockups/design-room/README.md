# A white room to design an object in

## v1 — proposed 2026-10-15

![v1](v1.png)

The Construct from *The Matrix* as a mode of its own: **Design here** on the
map's ring (beside Build) fades the world to white and leaves the object, your
avatar for scale, a metre grid and a faint outline of the spot's kerb and
facade. The tools are today's Edit dialog (Basics, Shape, Surface) docked on
the right, plus a parts list on the left. **Place** fades the world back in
with the object standing on the spot, sent to the server as one act; until
then it is a draft on the device that nobody else sees.

Not decided yet; the sheet ends with the open questions and a recommended
answer to each (several parts placed as one group, drafts on the device, the
avatar as a static scale figure, the spot outline on by default, studio light
with the spot's sun one tap away, no library export in v1, Build kept).
